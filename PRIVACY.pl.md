# Prywatność

TimeSheetLite przechowuje wpisy w przeglądarce na używanym urządzeniu. GitHub Pages udostępnia tylko pliki statycznej aplikacji, nie otrzymuje ani nie przechowuje wpisów obecności. Aplikacja nie tworzy kont i nie wysyła wpisów obecności autorowi.

- Dane w przeglądarce i kopie JSON nie są szyfrowane.
- Opcjonalna funkcja lokalnego pliku JSON korzysta z wyboru plików w przeglądarce. Wybrany plik jest odczytywany i zapisywany na urządzeniu, nie jest przesyłany przez aplikację. Przeglądarka może ograniczać tę funkcję poza HTTPS lub w nieobsługiwanych przeglądarkach.
- Każda osoba mająca dostęp do profilu przeglądarki, urządzenia lub pliku kopii może odczytać dane.
- Wybór kraju świąt innego niż Polska wysyła do Nager.Date tylko wybrany rok i kod kraju w celu pobrania świąt. Wpisy obecności nie są wysyłane.
- Korzystaj z zaufanego urządzenia, chroń kopie zapasowe i usuwaj dane, których już nie potrzebujesz.

Oprogramowanie jest udostępniane w stanie, w jakim się znajduje. Autor nie może zabezpieczyć danych po opuszczeniu przez nie przeglądarki lub urządzenia i nie odpowiada za utratę ani ujawnienie danych spowodowane niezabezpieczonym urządzeniem, profilem przeglądarki lub kopią zapasową.
