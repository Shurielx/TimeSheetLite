# Privacy

TimeSheetLite stores entries in the browser on the device being used. GitHub Pages only serves the static files; it does not receive or store attendance entries. The app does not create accounts or send attendance entries to the author.

- Browser storage and JSON backups are not encrypted.
- The optional local JSON data-file feature uses the browser's file picker. The selected file is read and written on the device; it is not uploaded by the app. The browser may restrict this feature outside HTTPS or unsupported browsers.
- Anyone with access to the browser profile, device, or backup file may be able to read the data.
- Choosing a holiday country other than Poland sends only the selected year and country code to Nager.Date to download public holidays. Attendance entries are not sent.
- Use a trusted device, protect backups, and remove data you no longer need.

The software is provided as-is. The author cannot secure data after it leaves your browser or device and is not responsible for loss or disclosure caused by an unsecured device, browser profile, or backup.
